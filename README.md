# Напоминалка с повторяющимися напоминаниями

## Описание

Это приложение для управления напоминаниями с возможностью установки повторяющихся уведомлений. Приложение позволяет создавать напоминания, которые будут автоматически повторяться по заданному графику.

## Особенности

- Создание обычных и повторяющихся напоминаний
- Поддержка различных интервалов повторения:
  - Ежедневно
  - Еженедельно
  - Ежемесячно
  - Ежегодно
  - Каждые X минут
  - Каждые X часов
  - Каждые X дней
- Автоматическое уведомление пользователя
- Фильтрация по статусу напоминаний
- Управление статусами (ожидает, готово, просрочено, отменено)

## Установка

1. Убедитесь, что у вас установлен Python 3.6+
2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

### Запуск приложения
```bash
python reminder_app.py
```

### Создание повторяющегося напоминания
1. Введите заголовок напоминания
2. При необходимости добавьте описание
3. Укажите дату и время срабатывания
4. Выберите интервал повторения из выпадающего списка
5. Нажмите "Добавить напоминание"

### Управление напоминаниями
- **Фильтры**: Фильтрация по статусу (Все, Ожидает, Готово, Просрочено, Отменено)
- **Управление**: 
  - Обновить список
  - Удалить выбранное напоминание
  - Отметить как Готово
  - Отметить как Отменено

## Техническая информация

### Структура базы данных
База данных SQLite содержит таблицу `reminders` с полями:
- `id`: уникальный идентификатор
- `title`: заголовок напоминания
- `description`: описание напоминания
- `reminder_datetime`: дата и время срабатывания
- `status`: статус напоминания
- `created_at`: дата создания
- `repeat_pattern`: шаблон повторения (если есть)

### Поддерживаемые шаблоны повторения
- `ежедневно` - повторять ежедневно
- `еженедельно` - повторять еженедельно
- `ежемесячно` - повторять ежемесячно
- `ежегодно` - повторять ежегодно
- `каждые_X_минут` - повторять каждые X минут
- `каждые_X_часов` - повторять каждые X часов
- `каждые_X_дней` - повторять каждые X дней
